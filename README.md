# Godot Movement System & State (Sandbox)

This repository is just a personal sandbox for experimenting with movement systems and state machines in Godot.

It is not a finished project, not a template, and not meant to be production-ready. Mostly just trial and error while learning.

## About

This repo contains various experiments related to:

- Character movement
- State machine (FSM)
- Different approaches to structuring player logic

Some parts may be incomplete, messy, or abandoned halfway.

## Purpose

- Learn how movement works in Godot
- Understand finite state machines
- Explore different implementation styles
- Track personal learning progress

## What’s Being Tested

- Idle / Walk / Run
- Jump and gravity
- State transitions
- Basic modular state system
